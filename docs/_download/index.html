💻 CLI — macOS (Apple Silicon)

Terminal client for scripting and headless transfers on Apple Silicon Macs.

Download CLI (Apple Silicon)

After download: chmod +x envoix-macos-aarch64 && ./envoix-macos-aarch64 --help

💻 CLI — macOS (Intel)

Terminal client for Intel-based Macs.

Download CLI (Intel)

After download: chmod +x envoix-macos-x86_64 && ./envoix-macos-x86_64 --help

🐧 CLI — Linux (x86_64)

Static musl binary. Works on any modern Linux distribution.

Download CLI (Linux)

After download: chmod +x envoix-linux-x86_64 && ./envoix-linux-x86_64 --help

🪟 CLI — Windows (x86_64)

Standalone .exe. No runtime required — just run it.

Download CLI (Windows)

Open PowerShell or cmd in the download folder and run: .\envoix-windows-x86_64.exe --help
