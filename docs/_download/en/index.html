CLI

The same transfer core, in your terminal.

The command is envoix and can be built from source on macOS, Linux, and Windows.

Rust 1.91+macOSLinuxWindows
View CLI source and documentation →
Install
$ git clone --branch v0.2.0 --depth 1 https://github.com/ECE4410J-NUUB/envoix.git
$ cd envoix
$ cargo install --path apps/envoix-cli
$ envoix --help
Receive
$ envoix receive --auto --output ./received
Send
$ envoix send --invite 'envoix:<base64url>' ./hello.txt
