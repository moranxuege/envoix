Verify before connecting

Device authentication and durable trust establish an explicit security boundary for reconnection.

Saved before delivered

The sender reports delivery only after receiver verification and durable-save confirmation.

Independent of the window

A desktop background service owns persistent work, so transfers can continue after the graphical window closes.

Upgrading to v0.3

v0.3 uses a new local state format. Keep received files and back up old state, then follow the recovery guide to reset legacy product state and pair devices again. Android’s new signing identity may require uninstalling a test-signed version first; uninstalling clears its application data.
